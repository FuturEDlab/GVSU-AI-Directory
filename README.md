
# LakerAI Vetting Hub 🏛️🤖

The unofficial community-led directory for AI tools at Grand Valley State University (GVSU). Built for Lakers, by Lakers, to audit the future of academic technology.

## 🌟 Mission
LakerAI is an **unofficial community vetting space**. It serves as a student-led platform for peer-reviewing, auditing, and experimenting with Artificial Intelligence resources. We prioritize critical literacy, ethical stewardship, and community-driven discovery over administrative mandates.

## ✨ Key Features
- **Community Vetting**: Submit and peer-review AI tools for institutional use.
- **Smart Discovery**: Tiered image retrieval (OG-scraped, Brand logos) ensures a professional look.
- **Governance Workflow**: Submitted tools move through a "Lifecycle Queue" where they are audited before public indexing.
- **AI-Powered Review**: Uses Google Gemini to generate pedagogical narratives that frame tools for critical academic review.
- **Real-time Feedback**: Global Laker likes, dislikes, and institutional tagging (FERPA, PII, Ethics).

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + ShadCN UI (GVSU Branded)
- **Database & Auth**: Firebase (Firestore & Laker Google Auth)
- **AI Integration**: Genkit + Google Gemini 1.5 Flash
- **Language**: TypeScript
